# Project Rules & Customizations

- **Git Commit Messages**: Always use Chinese for Git commit messages (例如: `git commit -m "优化5年跨度十字线滑动性能"`). **Strictly prohibit** including any AI/LLM model references, signatures, or badges in commit messages (e.g., NO `committed by Opus`, NO `Co-authored-by: Claude`, NO `Generated by AI`). Keep messages focused purely on technical changes.
- **Git Commit & Push Policy**: DO NOT perform `git commit` or `git push` automatically. Only execute git commit or git push when explicitly requested or confirmed by the user.
